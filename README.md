This project presents the design and implementation of a
scientific calculator that applies compiler construction principles
using Lex and Yacc. Unlike traditional calculators that perform
direct arithmetic computations, this system interprets and
evaluates mathematical expressions through lexical and syntax
analysis, mimicking the behavior of a compiler. The backend,
built using Flex (Lex), Bison (Yacc), and GCC, performs
accurate computation of arithmetic, trigonometric, logarithmic,
and exponential operations. A Flask-based web interface serves
as the frontend, allowing real-time user interaction and dynamic
result display. The integration of compiler logic with a web
application not only enhances functionality but also demonstrates
the practical application of system software concepts in
developing interactive computational tools. Overall, the project
bridges the gap between theoretical compiler design and modern
web-based computing, providing both educational value and
real-world utility.
Index Terms —
Lexical Analysis, Syntax Parsing, Compiler Design, Lex (Flex),
